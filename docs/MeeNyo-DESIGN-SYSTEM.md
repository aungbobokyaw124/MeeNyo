# MeeNyo Design System v1.0

## Product direction
MeeNyo is a Myanmar-first short-video, creator and community platform. The reference UI is inspiration only; do not copy another platform's UI.

## Hard visual rules
- Primary content aspect ratio: **4:5**.
- Profile content/video tiles: **4:5**.
- Do **not** design the product around TikTok-style 16:9 cards.
- Profile must have a distinctive, premium 4:5 identity.
- Myanmar-first copy and UX.
- Visual direction: dark premium base with Myanmar red and warm gold accents.
- The interface should feel modern, compact, polished and creator-focused.

## Initial screens
1. Home: For You / Following / Hot
2. Video viewer/feed
3. Create / Video editor
4. Trending Challenges
5. Creator Profile
6. Search
7. Notifications
8. Authentication / onboarding

## Profile direction
- Large distinctive profile header.
- Creator statistics: Following / Followers / Likes.
- 4:5 video grid.
- Strong creator identity instead of a generic social profile.
- Support creator tools and future earnings.

## Asset convention
Place supplied visual assets under `assets/images/` and preserve the original filenames where practical. Use supplied brand/logo imagery instead of inventing replacement branding once assets are available.

## Engineering direction
Current repository already contains the MeeNyo Expo app and an existing camera/Short Story flow. Extend the existing app carefully rather than deleting working functionality blindly. Keep the app buildable after each feature milestone.
